# 0011 — Explicitly verified Free Tier Gemini generation

Accepted for milestone 09, 2026-10-21, following `beb528a`.

Use pinned official `@google/genai` in the backend AI package. The only cloud generation model is `gemini-2.5-flash-lite`. Explicitly disable enterprise/Vertex, SDK retries, automatic continuation and thinking. Request one bounded text/JSON candidate. No tools, managed file search, grounding, batch, cache, paid model, provider switching or external messaging is integrated. Egress is restricted to the exact standard HTTPS generateContent endpoint; redirects are rejected. Tests inject transport while exercising the real SDK.

A working key cannot establish billing tier, and the SDK has no per-call free-only billing switch. Require a manual AI Studio Free Tier / billing-disabled assertion bound to project ID and key SHA-256, expiring after 24 hours, checked before every call. This is an operator assertion, not an automatic billing audit. External account changes invalidate its precondition. Missing, unverified, rotated or expired credentials fail closed. Never enable billing or infer free eligibility from success.

Only allowlisted synthetic organizations reach the adapter. Workers still reload authoritative membership/ticket/tenant state. Existing RAG, evidence validation, human review, edits, rejection and atomic internal-only replies remain. Free Tier content may be used to improve Google products; workspace scope is not a sensitive-data detector, so operators must keep that workspace synthetic.

The current embedding pipeline, vector storage, foreign keys and retrieval predicates are pinned to the synthetic 64-dimensional profile. The user did not confirm project free quota for `gemini-embedding-2` and explicitly requested preserving embeddings in that situation. No embedding API, migration or reindex is implemented here. Gemini generation consumes real tenant-filtered PostgreSQL hybrid retrieval with synthetic query vectors and lexical reranking. A future confirmed embedding change requires a separate model/dimension profile, staged versioned reindex, validated atomic cutover and preservation of the old index on failure. No semantic Gemini embedding quality is claimed.

An injected Redis guard atomically reserves rolling minute/day request budgets and leases across replicas, keyed by Google project. Defaults: 2/minute, 10/day, one concurrent call. Failures/timeouts retain reservations; Redis downtime stops calls. SDK retries are disabled; transient jobs permit at most two application attempts with backoff/Retry-After. All provider 429 responses conservatively pause for at least 24 hours, stop the job after one attempt and create a durable replayable DLQ entry. No fallback occurs. Model/authorization failures also pause conservatively. Request admission, including replay, checks current availability inside the idempotent mutation, preserving receipt replays.

A short-lived worker heartbeat supplies authenticated tenant-aware status. Gemini Live requires observed success for the verified key. Errors remain visible through cooldown; a bounded transient retry or later explicit request may establish recovery. Metrics use fixed provider/model/operation labels, never keys, project/tenant IDs or text. Unknown token usage remains unknown; zero Free Tier API estimates exclude infrastructure costs.

Measured limitation: two bounded live attempts produced no draft; the diagnostic returned HTTP 404/NOT_FOUND for the requested model. Google's model page restricts 2.5 access to previous users, consistent with a possible project entitlement restriction. Do not substitute another model or claim live success. The operator must obtain free access to the exact model or explicitly authorize a separately verified change.
