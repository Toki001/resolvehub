# Milestone 07 — CI/CD and production image delivery

Verified locally on 2026-10-21 with Node 22.22.3, pnpm 12.10.1, macOS arm64 and Docker Desktop. This is local evidence, not a claim of a remote Actions run, GHCR push or production deployment.

## Delivered

- Read-only pull-request/merge-queue/reusable CI with frozen installs, formatting/lint, strict types, OpenAPI and GraphQL generation drift, Jest unit/contract/integration coverage, PostgreSQL/Redis/MinIO isolation, clean/repeated/rollback/expanded/checksummed migrations, dependency audit and production Docker build/runtime smoke checks. A required aggregate fails on any failed, skipped or cancelled dependency.
- Push-only main/stable-version-tag release workflow, full verification before publication, protected-main/ancestry authorization, environment boundary and separate web/API/worker GHCR matrix. Only publishing receives packages write permission; it uses GITHUB_TOKEN. No PR publishing/login or inherited secrets. Official third-party action refs are full commit pins; the workflow validator rejects floating external refs.
- Digest-pinned Node base, one multi-stage build graph with three production targets, production service closures, canonical contract/migration assets, standalone Next.js/static assets, non-root UID 10001, container liveness checks and runtime secret-file preload. The local compiled web start command packages assets and launches the standalone server on loopback.
- Unique full-SHA/run/attempt image tags, minimal BuildKit provenance and per-component digest artifacts. Application-tier Compose, TLS proxy example, external-secret configuration, deployment validation, migration/grant command, release/rollback guide and repository/registry protection checklist.
- Faker upgraded from 9.9.0 to fixed 10.5.0. A visible, narrow unpatched braces development-only audit exception expires 2026-11-21; tests ensure production/new/fix-available/expired findings cannot use it. No broad audit suppression. Failed-start container cleanup uses reserved test-owned names; Jest ignores standalone package copies.

## Failures found and resolved

- Offline `pnpm deploy` failed because pnpm 12's deployment policy check needed additional full registry metadata. Production packaging now retains online metadata verification and the shared content store, following a frozen root install. All final images built and started successfully.
- One initial isolated-suite run timed out while Docker published a test container port during concurrent image builds. Its labeled disposable container was identified and removed without touching Compose. The suite passed subsequently; both harnesses now reserve and clean failed-start names, including one-off migration containers and failed application starts.
- A strict test-fixture type initially inferred `patched_versions` as only null; its untrusted input is now explicitly unknown and validated by the audit parser. Strict typechecks pass.
- A sandbox-only check failed creating tsx's local IPC pipe. Rerunning with local execution permission passed; no application behavior was changed to bypass this environmental restriction.
- Standalone output introduced duplicate package manifests into Jest discovery; excluding `.next` resolves the naming collisions. A tightened GraphQL smoke assertion initially omitted the required request-ID extension; it now validates both structured data and request/header correlation. The final container smoke and complete Jest coverage suite pass.

## Limits and handoff

No Git remote is configured in this workspace. Remote required-status names, branch/tag rules, environment approval, GHCR package visibility/permissions, Actions execution and image publishing remain unverified. Apply [the protection checklist](../operations/branch-protection.md) and complete the first protected-main/tag run before trusting remote delivery. No images were pushed and no production credentials/host were used locally.

Release images target Linux amd64 on GitHub-hosted Ubuntu 24.04; local image execution measured Linux arm64. CI is configured to build/smoke the native amd64 images, but that remote result is not claimed. MinIO's pinned source build was reused from the local cache; its existing Go/Alpine toolchain tags are not digest pinned. There is no production backup restore, traffic cutover or previous-digest production rollback measurement; those are documented operator procedures. GHCR tags are not inherently immutable, so unique run tags, restricted writers and digest-based deployment are all required.

The live advisory check currently reports the documented unpatched dev-only exception; it expires automatically on 2026-11-21. Application limitations from milestone 06 remain: synthetic embeddings/mock drafting do not establish live-model quality or performance, dashboard authentication/data integration is incomplete, and there is no outbound customer messaging. Telemetry belongs to milestone 08.
