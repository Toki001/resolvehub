# Generated client

`src/rest.ts` is generated by openapi-typescript. `src/graphql/` is generated by GraphQL Code Generator's client preset using the canonical SDL and operation documents. Never hand-edit these files.

`src/index.ts` exposes the openapi-fetch factory (optional bearer credential) and typed GraphQL document constants. `codegen.ts` uses explicit ESM import extensions, strict scalar mappings and type-only imports. Run `pnpm generate`; `pnpm contracts:drift` rejects changed, deleted or untracked generated outputs. Generated sources are committed and checked in CI.
